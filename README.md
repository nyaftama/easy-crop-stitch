# かんたんクロップ結合ツール (Easy Crop & Stitch Tool - Batch Fixed-Region Cropper & Grid Stitcher)

複数画像から指定範囲を一括で自動切り抜きし、グリッドや一列に並べて1枚の画像に結合、または個別画像をまとめてZIPダウンロードできるWebアプリケーションです。  
ゲーム攻略のステータス比較、検証画像の並び一覧、動画サムネイル制作、ECサイトのカラーバリエーション一覧、資料作成など、複数枚のスクリーンショットや写真から特定エリアを定点抽出して綺麗にレイアウトしたい作業をブラウザ完結で手軽に実現します。

- **Webアプリ**: [https://nyaftama.github.io/easy-crop-stitch/](https://nyaftama.github.io/easy-crop-stitch/)
- **作者**: [@nyaftama](https://nyaftama.github.io/)

## 主な機能

1. **複数画像の一括定点・指定範囲切り抜き**
   - 1枚目の基準画像上でドラッグまたは8方向ハンドル操作により、切り抜き範囲（X, Y, 幅, 高さ）を直感的に指定
   - 1px単位の精密な数値入力や、「全体を選択」「中央に配置」「正方形(1:1)」のクイックアクションに対応
   - 読み込んだすべての画像から同一の指定領域を一括で自動トリミング

2. **自由なグリッド結合レイアウト**
   - 列数（1〜12列、横1列・縦1列・自動正方グリッドプリセット）を自由自在に調整
   - 画像同士の間隔（すき間: 0px / 8px / 16px / 64px プリセット ＆ スライダー）のピクセル調整
   - 外枠の余白（余白: 0px / 8px / 16px / 64px プリセット ＆ スライダー）のピクセル調整
   - 背景色（透明・白・黒・カラーピッカーによるカスタムカラー）のカスタマイズ

3. **3種類のカスタム配置順（Z配置 / N配置 / S配置）**
   - **Z配置（横書き）**: 1行目を左から右へ並べ、次の行へ折り返す標準的なレイアウト
   - **N配置（縦書き）**: 右上の列から下方向へ並べ、次の列は左隣の上から並ぶ、縦書き書籍や漫画のようなレイアウト
   - **S配置（蛇行・ブストロフェドン）**: 偶数行は左から右へ、奇数行は右から左へと折り返す蛇行レイアウト

4. **並び順のドラッグ並び替え ＆ ファイル名自動ソート**
   - サムネイル一覧でカードをドラッグ＆ドロップして並び順を直感的に入れ替え
   - ファイル名の昇順（A→Z）および降順（Z→A）での一括自動ソートに対応
   - 各カードの左上に配置インデックスバッジを表示し、並び順をひと目で把握可能

5. **誤操作を防ぐ安全な削除モード**
   - 誤タップ・誤クリックによる画像の誤削除を防ぐ専用の「削除...」モードを搭載
   - 削除モード中は各サムネイルに削除バッジが表示され、タップした画像のみを除外
   - 完了ボタンを押すことで通常モードに安全に復帰

6. **結合画像保存 ＆ 個別切り抜き画像のZIP一括ダウンロード**
   - 結合した1枚の画像をPNG（高画質・透過対応）、JPEG（軽量）、WebP（高圧縮）から選択して保存
   - 個別に切り抜いた各ピースを連番ファイル（`crop_001.png`, `crop_002.png` ...）としてまとめたZIPアーカイブの一括保存に対応
   - 結合保存・ZIP保存のいずれも、モーダル内で選択した保存フォーマットや背景色が自動適用

7. **HEIC/HEIF画像フォーマット対応**
   - iPhoneやiPad等で撮影された `.heic` / `.heif` 形式の画像もブラウザ内で自動変換して直接読み込み可能
   - PNG, JPEG, WebP, GIF など幅広い主要画像フォーマットに対応

8. **完全ブラウザ完結処理で安全＆高速（外部サーバー送信なし）**
   - すべての画像処理が端末（ブラウザ）内の HTML5 Canvas API で完結
   - 画像データが外部サーバーへ送信・保存されることは一切ないため、プライベートな写真や機密画像も安全に処理可能

9. **完全無料 ＆ 個人・商用利用可能**
   - 会員登録不要・完全無料で全機能をご利用いただけます
   - 個人利用・商用利用（Webサイト、動画、出版物、SNS等）問わず自由にご活用いただけます

## 使い方

1. **画像を準備・読み込む**
   - 切り抜きたい複数画像をスタート画面のドロップゾーンにドラッグ＆ドロップ、またはファイル選択ダイアログからまとめて読み込みます。
   - すぐに操作を試したい場合は「サンプル画像で試す」をクリックすると、デモ画像4枚が即座に生成されます。

2. **切り抜き範囲を指定する**
   - ワークスペース左側の「切り抜き範囲」パネルで、水色のクロップ枠をドラッグして位置・サイズを合わせます。
   - 上部の「全体を選択」「中央に配置」「正方形(1:1)」や、下部の数値入力（X, Y, W, H）でも微調整可能です。

3. **結合レイアウト・配置順を設定する**
   - 「結合レイアウト設定」パネルで、列数、画像間のすき間、外枠の余白、および配置順（Z配置 / N配置 / S配置）を調整します。

4. **並び順の確認・整理**
   - 「並び順の管理」パネルでサムネイルをドラッグして順序を入れ替えたり、ファイル名ソート（昇順・降順）を実行します。不要な画像がある場合は「削除...」ボタンを押して除外します。

5. **画像を保存する**
   - ヘッダーの「画像を保存」をクリックして保存モーダルを開きます。
   - 完成サイズや処理枚数を確認し、保存フォーマット（PNG / JPEG / WebP）と背景色を選択します。
   - 「結合画像を保存」をクリックすると1枚に結合された画像がダウンロードされます。個別画像が必要な場合は下部の「切り抜き画像をまとめて保存（ZIP）」をクリックします。
